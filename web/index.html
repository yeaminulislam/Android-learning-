ইনস্টল যেভাবে

  1. ফোনে ব্রাউজার থেকে উপরের বোতামে ট্যাপ করে APK নামান।
  2. নোটিফিকেশন বা Files অ্যাপ থেকে ফাইলটি ট্যাপ করুন।
  3. “অজানা অ্যাপ ইনস্টল করা” অনুমতি চাইলে Allow দিন (এটি প্লে-স্টোরের বাইরের অ্যাপ, তাই স্বাভাবিক)।
  4. ইনস্টল শেষে Open — প্রথমবার ৫–৪০ সেকেন্ড ডেটাবেস প্রস্তুত হবে।
  5. কম্পিউটার থেকে দিতে চাইলে: adb install -r prakriti-kosh.apk
